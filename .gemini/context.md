# Project Context: Vue to React

This file provides the core context for Antigravity to ensure continuity across chat sessions.

## Mission
To build a high-quality development handbook and documentation site that assists developers in understanding concepts and transitioning their mental models from Vue to React.

## Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite 6+
- **Content:** MDX (Markdown for component-rich docs)
- **Styling:** Tailwind CSS v4 + Sass-embedded
- **Package Manager:** pnpm

## Folder Structure
We follow a simplified, standard React layout:
- `src/assets/` - Static brand assets
- `src/components/` - Reusable components (`layout`, `ui`, `docs`)
- `src/content/` - MDX documentation files
- `src/pages/` - Route-level view components
- `src/hooks/` - Custom React logic
- `src/lib/` - Utilities and tool configurations
- `src/styles/` - Global styling entry points
- `src/types/` - TypeScript definitions
- `src/data/` - Static metadata and nav configs
